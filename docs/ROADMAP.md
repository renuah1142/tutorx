# TutorX Roadmap

## Phase 1: Static interactive release

- [x] Create responsive application shell and visual design.
- [x] Add 11-section curriculum map.
- [x] Add lesson studio with lesson completion.
- [x] Add flashcards and section filtering.
- [x] Add scored quizzes with answer explanations.
- [x] Add outage-detective scenarios.
- [x] Add IPv4 subnet calculator and practice questions.
- [x] Add interview question bank and mock answer practice.
- [x] Add glossary, dashboard, progress report and JSON export.
- [x] Add local persistence, XP, badges, dark/light theme and responsive layout.
- [x] Document product, curriculum, learning design, architecture, deployment and contributions.
- [ ] Complete browser smoke tests and verify GitHub Pages deployment after merge.

## Phase 2: Learning quality

- Expand each section into deeper lessons with diagrams and worked examples.
- Add mixed-section quizzes and configurable timed practice.
- Add missed-question review and spaced repetition scheduling.
- Track topic mastery and make dashboard recommendations from actual learner performance.
- Add more subnetting questions, binary walkthroughs and step-by-step answer checks.
- Add accessible keyboard-first matching and drag-free alternatives.

## Phase 3: Simulation and realism

- Build an interactive OSI packet journey.
- Build a network topology simulator with endpoint, switch, router and provider access nodes.
- Add fault-injection exercises in a simulated environment only.
- Add ticket-writing practice with a rubric.
- Add a major-incident timeline and shift-handover exercise.
- Add interface-counter and monitoring-alarm case studies.

## Phase 4: Maintainability and quality assurance

- Split large inline code into source modules if justified.
- Add unit tests for IPv4 calculations, quiz scoring and progress state.
- Add linting and accessibility checks if a build/test toolchain is introduced.
- Add content tags and references per question.
- Add a content review checklist for technical accuracy.

## Phase 5: Optional enhancements

- Import/export complete study plans and card schedules.
- Optional cloud sync only after privacy and authentication design.
- Optional AI tutoring only after explicit consent, budget, privacy, security and error-handling decisions.
- No feature should require a paid API for the basic course to remain usable.
