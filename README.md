# TutorX

TutorX is an interactive, browser-based networking tutor and interview-preparation game designed around the CSC Tier 1 Engineer, B2B role.

The repository is intentionally starting as a lightweight static site so it can be hosted on GitHub Pages without a paid backend or build step.

## Project status

The first release will include a responsive learning dashboard, an 11-section curriculum map, interactive lessons, flashcards, scored quizzes, XP and badges, browser-local progress, a subnetting practice area, troubleshooting scenarios, interview practice, and project documentation.

## Quick start

Open index.html in a modern browser, or serve the repository root with any static web server. No package installation is required.

## Important learning note

TutorX is an educational aid. Network commands and troubleshooting actions must only be used on systems and services you are authorized to test. Provider-specific workflows, SLAs, and escalation policies must follow the employer's procedures.
